## ✨ What's This?

An interactive terminal-style portfolio where you can type commands to explore my work, skills, and projects. It's like using a command line, but way more fun!

### Features
- 🖥️ Terminal-style interface
- 🎨 Matrix rain animation
- ⚡ Particle effects
- 📱 Works on mobile too
- 🎭 Multiple color themes
- ⌨️ Keyboard shortcuts

---

## 🎮 How to Use

Just type commands like:
- `about` - Learn about me
- `skills` - My tech skills
- `projects` - Check out my projects
- `contact` - Get in touch
- `resume` - Download my resume
- `help` - See all commands

Or just click the buttons below the terminal!
